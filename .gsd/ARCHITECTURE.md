1. User interacts with UI, triggering functions via `window.POS_DB` (exposed from `src/index.js`).
2. `creditEngine.js` and `settlementEngine.js` process transactions locally in RxDB.
3. `syncEngine.js` synchronizes offline transactions to Supabase/Firebase in the background when online, utilizing RxDB leader election.
4. `supervisorEngine.js` and `aiAuditEngine.js` run background checks to audit data anomalies.
