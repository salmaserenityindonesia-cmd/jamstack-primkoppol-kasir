Sistem POS & Ekosistem Manajemen Koperasi Waserda PRIMKOPPOL NGAWI.

## Data Flow

1. Kasir melakukan input transaksi di UI (HTML Module).
2. UI memanggil fungsi bisnis di `window.POS_DB` (contoh: `processTransaction()`).
3. Business engine (`creditEngine.js`) memvalidasi plafon. Jika lolos, data disimpan ke lokal `transactions` RxDB (`sync_status: 'PENDING'`).
4. RxDB menggunakan Leader Election. Tab yang menjadi leader akan menyalakan `syncEngine.js`.
5. `syncEngine.js` mendeteksi transaksi pending dan mem-push payload ke Supabase Cloud (FIFO) lalu mengubah status jadi `SENT`.
