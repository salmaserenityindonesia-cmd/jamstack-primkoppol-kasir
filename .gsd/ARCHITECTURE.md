## Data Flow

1. User interacts with UI (e.g., adds product, completes transaction).
2. UI updates local RxDB state instantly.
3. RxDB Leader Election ensures only one tab triggers sync.
4. SyncEngine pushes/pulls changes to/from Supabase asynchronously.
